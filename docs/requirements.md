# 要件定義書

## 1. 目的
League of Legends の試合中に発生するハイライトを簡単に保存するためのデスクトップアプリケーションを提供する。OBS または ffmpeg を利用した録画機能と、保存した動画の閲覧機能を備える。

## 2. 利用環境
- Rust と pnpm がインストールされた開発環境
- OBS Studio 5 以降および WebSocket プラグイン【F:README.md†L8-L11】
- ffmpeg コマンドが実行可能であること【F:README.md†L8-L11】
- League of Legends クライアントを起動した状態で利用する【F:README.md†L8-L11】

## 3. 機能要件
1. **録画モード切替**
   - OBS を利用した録画と ffmpeg を利用したシェル録画を選択可能。
   - ユーザー設定により録画モードを保存できる。
2. **録画操作**
   - 録画開始 / 停止
   - リプレイバッファ開始 / 停止 / 保存
3. **LoL イベント連携**
   - LoL クライアントの API をポーリングし、`Multikill` 等のイベント検出時に自動でクリップ保存を行う【F:src-tauri/src/lib.rs†L628-L704】。
4. **動画保存先の指定**
   - 保存ディレクトリを設定画面から指定し、設定値を保存可能【F:src/settings.js†L110-L130】。
5. **動画一覧表示と再生**
   - クリップされた動画を一覧表示し、選択した動画をアプリ内で再生する【F:README.md†L86-L98】【F:src/videos.js†L1-L36】【F:src/video.html†L1-L29】。
6. **設定ファイルの読み込み／保存**
   - アプリ起動時に設定ファイルを読み込み、画面から変更した内容を保存できる【F:src/settings.js†L147-L159】。
7. **デバイス情報取得**
   - ffmpeg モードでは利用可能な録画デバイス一覧を取得し、セレクトボックスへ展開する【F:src/settings.js†L168-L202】。
8. **デスクトップ通知**
   - リプレイバッファ開始・停止・保存、録画開始・停止時にデスクトップ通知を表示する。
9. **ゲームセッション管理**
   - ゲーム開始〜終了を 1 セッションとし、セッション中に保存した動画ファイルの一覧を保持する。

## 4. 非機能要件
- Mac / Windows / Linux での動作を想定（Tauri がサポートするプラットフォーム）。
- 録画ファイルは `mp4` 形式で保存し、同名の `json` にイベント情報を書き出す【F:src-tauri/src/db.rs†L25-L39】。
- UI は Tailwind CSS を利用した簡易な HTML ページで提供する。
